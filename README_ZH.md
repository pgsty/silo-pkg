# silo-pkg

[English](README.md) · [简体中文](README_ZH.md)

Pigsty 维护的 [minio/pkg](https://github.com/minio/pkg) 分支，为 SILO Server、Console 与 mcli 提供共享包。维护模块为 `github.com/pgsty/silo-pkg/v3`，对未经修改的上游 MinIO 的兼容尽最大努力。

## 当前版本

**v3.16.1** 要求 **Go 1.27.4**，在严格 IAM 与桶策略解析中拒绝非对象 JSON 输入、尾部多余 token 及未知字段，防止拼写错误静默退化为空策略或丢失语句条件，并更新 x/sys、x/term、x/text、x/oauth2、gRPC、grpc-gateway 与 go-humanize 依赖，同时保留已验证的加密、minio-go 与 NetBSD 兼容选择。发布状态见 [GitHub Releases](https://github.com/pgsty/silo-pkg/releases)。完整变更见 [CHANGELOG.md](CHANGELOG.md)。

本模块仅发布源码，没有独立二进制或镜像。Server、Console 与 mcli 需分别采用 v3.16.1 并重新构建；本次库发布不会更新这些组件的既有发布制品。组件的独立发布状态见[版本矩阵](https://silo.pgsty.com/zh/compatibility/versions/)。

## 使用方法

直接声明模块，无需 `replace`：

```go
require github.com/pgsty/silo-pkg/v3 v3.16.1
```

```go
import "github.com/pgsty/silo-pkg/v3/policy"
```

`/v3` 是模块主版本，不能省略。v3.12.2 及更早版本保留上游 `github.com/minio/pkg/v3` 路径，通过 `replace` 选择；v3.13.0 起拥有独立模块路径。迁移时去掉旧替换，直接 require 本模块并修改 import。Go 不会继承依赖模块的 `replace` 指令。

仓库于 2026-08-02 从 `pgsty/minio-pkg` 更名。GitHub 保留重定向，新引用应使用当前名称。

## Go 与 TLS

库要求 Go 1.27.4 或更新版本。运行时行为由消费方应用的 Go 版本与 `GODEBUG` 决定，不仅取决于本库的 `go.mod`。Web 环境客户端沿用 Go 默认密钥交换，LDAP/OIDC 辅助函数保留调用方提供的 TLS 配置。

默认 TLS 配置下，`GODEBUG=tlsmlkem=0` 关闭混合密钥交换；`GODEBUG=tlssecpmlkem=0` 只关闭 SecP 混合组，保留 X25519MLKEM768。两者都不会关闭证书验证。

macOS 上，以 Go 1.27 为目标的应用设置 `SSL_CERT_FILE` 或 `SSL_CERT_DIR` 后，会改用磁盘根证书和 Go 验证器，不再沿用 Keychain 信任。过期或不完整的 CA 路径可能使原本可信的连接失败；移除继承变量可恢复 Keychain 行为。显式传给 `certs.GetRootCAs` 的 CA 仍追加到选定的根池中。使用旧版库且目标仍为 Go 1.26 的应用保留旧平台默认行为，除非启用 `GODEBUG=x509sslcertoverrideplatform=1`。本包直接读取 Windows ROOT 存储的行为不变，详见 [Go 发布说明](https://go.dev/doc/go1.27)。

## 版本与兼容性

本项目独立于上游发布。影响共享策略语义的更新应与 Server、Console、mcli 配套采用；不改变语义的补丁不要求同时发布所有组件。

v3.14.0 将自助改密与用户管理分开。从更早版本升级时，应检查拒绝 `admin:CreateUser` 或 `admin:ChangeMyPassword` 的策略，参见[密码权限迁移](https://silo.pgsty.com/zh/compatibility/password-permissions/)与 [UPSTREAM.md](UPSTREAM.md#breaking-authorization-compatibility)。v3.14.2 的 JOSE 更新拒绝超过 4096 位的 RSA JWK，使用该解析器的应用还需检查身份提供方配置。
